# Cylar Taylor — Official Artist Website

Official artist website for **Cylar Taylor**, built from the approved master October artist website template.

## Features
- **Hero Background & Visuals**: High-performance hero media and sharp poster frame extracted from Cylar Taylor's official visuals.
- **Discography & Stream Modal**: Direct multi-platform streaming and pre-save links (Spotify, Apple Music, YouTube Music, Deezer, Amazon Music, Tidal, iTunes, UnitedMasters Pre-Save) for 5 featured releases:
  - *Oh Hello* (Single / UnitedMasters Pre-Save, Nov 20, 2026)
  - *Alone* (Single, Oct 2, 2026)
  - *Must We* (Single, Jul 31, 2026)
  - *Blue Mountain* (Single, Jun 17, 2026)
  - *Somebody's Knockin'* (Single, Mar 20, 2026)
- **Videos Section & Latest Video Feature**: Official YouTube videos:
  - *Must We* (Live from Sedona)
  - *Somebody's Knockin'* (The Bonfire Sessions)
  - *Blue Mountain* (Live from Sedona, AZ)
- **Socials & Streaming Bar**: Verified icons and direct links for Spotify, Apple Music, YouTube, Instagram, and TikTok.

## Development & Deployment
```bash
# Install dependencies
npm install

# Run locally
npm run dev

# Type check
npm run lint

# Build for production
npm run build

# Deploy to Cloudflare
npx wrangler deploy
```
